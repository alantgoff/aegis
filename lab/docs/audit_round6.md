# Round-6 audit: the zoo9 family-selection result and the alignment-practice framing (2026-10-26)

Two auditors (protocol+code; numbers+claims), each followed by a skeptic. 33 raised, 29 confirmed, all adopted.
Scope: the sealed zoo9 result (H20–H22, `analysis/family_select.py`, `results/zoo9_H20_H22.txt`), Summary item 5,
§3.10, the "Use for alignment practice" section, the README top and `llm/coverage_audit.py`'s printed verdict.

Main corrections:
- The zoo9 test used the toy oracle rate (true poison gradient) and 100%-single-program arms. It does not validate
  `llm/coverage_audit.py`, which ranks 25% text-augmentation mixtures from a few observed instances and has not been
  run on any model. "Validated" wording was removed from the README and REPORT.
- A fixed best-family baseline (always periodic: 19/31; forecast 12 vs 2 discordant, p = 0.006) and the
  kind-level structure of the 29/31 are now reported, with the tie (28/31 strictly) and the two total misses.
- Single-program fine-tuning cost clean accuracy (0.977 vs 0.995 under P); now reported.
- The README's "persists exactly when" and "the same set" claims, the "one gradient pass" cost claim and the
  rate-sign yes/no verdict were replaced by the measured tendencies. `llm/coverage_audit.py` now prints rates for
  ranking with no erode/persist verdict.
- Correlation ranges, headings, provenance wording, the Pythia base-model note, zoo7/zoo8 numbers and the zoo9
  artefact exclusions (b0025, b0029; now in `analysis/asr_coincidence.py`'s scan) were corrected.
- Registered analysis code (`analysis/family_select.py`) was not changed; all fixes are to text, plus the
  descriptive artefact scan and the CLI's printout.
